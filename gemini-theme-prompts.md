# Gemini Image Generation Prompts — Backgammon Themes 4–7

> **Usage:** Copy each prompt block exactly into Gemini (or Imagen 3). Each prompt generates one complete asset sheet per theme.
> The board layout must exactly match the reference: two quadrants, 12 points each (6 top / 6 bottom), center bar, two stacked rectangular panels on the far right, thick outer frame.

## Notes for Gemini

- If the model adds unwanted text/UI overlays, add: `"No text labels, no UI elements, pure game asset illustration only."`
- If proportions drift, add: `"The board must fill at least 70% of the image width. Maintain strict 16:9 landscape ratio."`
- For higher quality: add `"ultra-detailed, studio lighting, 4K resolution game asset, professional mobile game art style"`
- Re-generate with seed variation if triangles are uneven — standard backgammon always has exactly 6 points per row per quadrant.
