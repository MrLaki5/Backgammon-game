## Icon Direction

Current icon should communicate:
- Premium / Royal feeling (gold + dark tones)
- Immediately recognizable as backgammon (dice or board element)
- Clean at small sizes (launcher icon)
- Distinctive from competitors (avoid generic dice-only icons)

**Recommendation:** Dark background with gold crown element over stylized backgammon triangles, subtle dice accent.
