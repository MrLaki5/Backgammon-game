# Economy Budget Reference
| Player type | Daily coins |
|---|---|
| Casual (2-3 games, no extra ads) | 40–60 |
| Active (with ad-watch + challenges) | 150–180 |

Pricing rules derived from this:
- Common cosmetics (frame/dice): 50–200 coins (1–3 days casual)
- Rare: 300–700 (5–12 days casual)
- Epic: 800–2000
- Legendary: 2500–5000
- Themes (coin-unlocked): 400–800 each (3–5 active days)
- No single base item should exceed 10 casual days (~600 coins)
