# Content Marketing Plan — 30 Days

## Platform Strategy
- **Instagram Reels** (primary — Persian gaming community)
- **YouTube Shorts** (secondary — broader reach)
- **Telegram** (community + direct distribution)

## Content Pillars
1. **Gameplay** — satisfying moves, close games, comebacks
2. **Feature Showcase** — themes, AI difficulty, two-player
3. **Education** — backgammon tips, strategy, rules
4. **Entertainment** — memes, relatable moments, challenges

## Telegram Strategy

- **Channel:** @RoyalBackgammon (announcements, updates, tips)
- **Group:** Community chat for players
- **Content mix:**
  - Update announcements
  - Daily tip posts
  - Strategy discussions
  - User screenshots/achievements
  - Poll: which theme, which difficulty
  - APK direct download link (for users without Bazaar)

---

## Production Notes

- All video content uses actual in-game footage (screen recording)
- Text overlays in Persian, gold color on semi-transparent dark background
- Background music from game OST (menu theme)
- No face-cam needed (gameplay-focused)
- Tools: Screen recorder + CapCut/InShot for editing
- Posting schedule: 1 per day, best times for Persian audience: 18:00-22:00 IRST
